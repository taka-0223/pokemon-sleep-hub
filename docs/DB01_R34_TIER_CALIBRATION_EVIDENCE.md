## 比較条件と用途の分離

- 食材数は [2026年6月のオイル比較](https://www.tofumentalpapa.com/entry/pksl_oil) と [ミルク比較](https://www.tofumentalpapa.com/entry/pksl_milk) を使用。食材確率M・性格無補正・日中毎分回収・睡眠中無回収・げんき81%以上という**同じ外部モデルの条件**で、Lv30とLv60を別々に比べた見積もりである。既存CURRENTにある個体PRとは定義が異なる。
- きのみは [ウブのみ](https://wikiwiki.jp/poke_sleep/きのみ/ウブのみ) と [ライチュウ](https://wikiwiki.jp/poke_sleep/ライチュウ) の基準手伝秒数・きのみ個数を使った**基礎効率のみ**。BFS・元気・食材確率・チーム・フィールドは含めない。
- `M_Rules R-005` はPRの固定閾値だけで判断しない、`R-006` はAAAパターンだけで判断しない、`R-009` はRoleSlot単位で意思決定すると定義する。**S/A+/Aへの一意な量的閾値は既存SSOTに未定義**。
