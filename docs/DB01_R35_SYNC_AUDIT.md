## 確認された不具合と限定修復

1. CURRENTの `P_Individuals.active` に、Excel論理値 `false` と文字列 `"False"` が混在。既存生成器は `is False` 判定だけだったため、`IND-0011`と`IND-0014`を誤って有効扱いし、37個体を生成した。真偽値の型を厳密に正規化し、不明な状態値は生成を失敗させる。
2. 公開r23の38個体すべてを将来も保持する前提だった `current-facts-merge.js` は、正式な博士送りを反映できなかった。SSOTから非アクティブIDを抽出し、総数・重複・activeとの排他性を検査する。旧公開から消えるIDは、明示された非アクティブIDに含まれる場合のみ許可する。
3. 旧公開r23では色違い `IND-0016` が「アメ化候補」と表示される。CURRENT r35の色違い確定を固定事実としてoverlayへ追加し、矛盾する旧送却提案は画面上で「キープ（色違い保護）」と注記する。品質・Tier・順位を新たに採点せず、旧判断データそのものも書き換えない。
4. UIでは旧公開の役割を正式な現担当と混同しないよう「旧評価の役割（参考）」と明示する。
